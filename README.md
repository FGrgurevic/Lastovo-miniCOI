# ISLAND2022-miniCOI

Code, metadata and analysis workflow accompanying the study:

**Targeted mitochondrial sequencing reveals zooplankton diversity patterns associated with island-trapped waves**

## Study overview

Zooplankton samples were collected south of Lastovo Island (Adriatic Sea) during the ISLAND field campaign in July 2022. Sampling was performed using 53 µm and 200 µm WP2 closing nets in upper and lower water-column layers during periods with and without island-trapped wave (ITW) activity.

Zooplankton diversity was characterized using a miniCOI metabarcoding approach.

## Repository contents

This repository contains scripts and supporting files used for:

- sequence processing and taxonomic filtering
- preparation of the holoplankton dataset
- alpha-diversity analyses
- community composition analyses
- PERMANOVA
- taxonomic composition summaries
- generation of figures used in the manuscript

Sequence processing was performed in QIIME 2 v2024.10, with DADA2 denoising and taxonomic assignment against the MetaZooGene COI reference database. Statistical analyses and visualization were performed in R.

## Sequence data

Raw miniCOI sequencing reads are deposited in the European Nucleotide Archive (ENA) under project accession:

**PRJEB63220**
